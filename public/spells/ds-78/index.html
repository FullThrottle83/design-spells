Smooth Multiline Text Fade Mask (`mask-image`)

Replaces the hard clip from `-webkit-line-clamp` with a soft faded alpha mask at the bottom of long text blocks.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<p class="text-fade-clamp">The faded mask replaces a hard line-clamp so the last visible line dissolves instead of being chopped mid-word. Extra copy keeps the fade honest.</p>

CSS

.text-fade-clamp {
  max-height: 9lh; /* Max 9 lines of text */
  overflow: hidden;
  mask-image: linear-gradient(to bottom, black 60%, transparent 100%);
  -webkit-mask-image: linear-gradient(to bottom, black 60%, transparent 100%);
}
