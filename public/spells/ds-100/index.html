Grid Lanes Masonry (`display: grid-lanes`)

Pinterest packing in CSS. `display: grid-lanes` fills the shortest column in DOM order (correct reading order, unlike `column-count`). Fallback is a regular grid.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Shared design tokens are supplied by the demo environment, not included in these snippets.

HTML

<ul class="lanes">
  <li><article class="card">Card 1</article></li>
  <li><article class="card">Card 2 with more text</article></li>
  <li><article class="card">Card 3</article></li>
</ul>

CSS

.lanes {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  gap: var(--space-4);
  align-items: start;
  list-style: none; padding: 0; margin: 0;
}
@supports (display: grid-lanes) {
  .lanes {
    display: grid-lanes;
    grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  }
}
