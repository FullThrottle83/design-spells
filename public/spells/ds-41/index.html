Content-Visibility Turbo

The rendering engine skips layout for elements outside the viewport. A big win on long pages.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<section class="lazy-section">Offscreen layout is skipped.</section>

CSS

.lazy-section {
  content-visibility: auto;
  contain-intrinsic-size: auto 500px;
}
