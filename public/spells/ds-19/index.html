Focus-Within Halo

Wrapper-based focus feedback for composite inputs and search boxes.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="input-group"><span aria-hidden="true">⌕</span><input type="search" placeholder="Search spells"></div>

CSS

.input-group {
  display: flex; align-items: center; gap: .5rem;
  border: 1px solid var(--color-border);
  border-radius: var(--radius-md);
  padding: 0 .75rem;
  transition: border-color 180ms cubic-bezier(0.16,1,0.3,1), box-shadow 180ms cubic-bezier(0.16,1,0.3,1);
}
.input-group:focus-within {
  border-color: var(--color-primary);
  box-shadow: 0 0 0 3px oklch(from var(--color-primary) l c h / 0.16);
}
.input-group input:focus-visible { outline: none; box-shadow: none; }
