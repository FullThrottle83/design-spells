Sticky CTA Elevation

A sticky bottom CTA gains more separation when it sits on top of content.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<p style="min-height:4rem">Content</p><div class="sticky-cta">Continue →</div>

CSS

.sticky-cta {
  position: sticky; bottom: 0;
  background: oklch(from var(--color-bg) l c h / .88);
  backdrop-filter: blur(10px);
  border-top: 1px solid var(--color-border);
}
