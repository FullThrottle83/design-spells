ds-46 / Scroll / 0 JS

Real Overflow Hint

Show edge fades, arrows, or “swipe me” hints only when the content is actually scrollable.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

Scroll to preview

Use the native Fit content checkbox to compare an overflowing row with one that wraps. The overflow arrow follows actual scrollability in supporting browsers; horizontal scrolling and readable labels remain available without the enhancement. These labels are a visual fixture, not working tab controls.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="tabs-wrap" style="max-width:20rem"><div style="display:flex;gap:1rem;white-space:nowrap;padding-inline-end:3rem;min-width:44rem"><span>Overview</span><span>Getting started</span><span>Pricing</span><span>Documentation</span><span>Changelog</span><span>Support</span><span>Community</span><span>Careers</span></div><div class="fade-hint">→</div></div>

CSS

.tabs-wrap {
  position: relative;
  overflow-x: auto;
  container-type: scroll-state;
}

.tabs-wrap .fade-hint {
  opacity: 0;
  transition: opacity 180ms ease;
}

@container scroll-state(scrollable: inline) {
  .tabs-wrap .fade-hint { opacity: 1; }
}

Verification evidence

  • behavior (2026-09-26, chromium 151.0.7922.34): Scoped ds-46 test with scripts disabled: measured positive overflow and hint opacity 1, checkbox removed overflow and opacity became 0, restoring overflow returned opacity to 1; both motion modes. — Source
  • behavior (2026-09-26, firefox 153.0): Fallback observation in both motion modes: checkbox toggled real overflow; unsupported scroll-state hint remained hidden; named scroller stayed available. — Source
  • behavior (2026-09-26, webkit 26.5): Fallback observation in both motion modes: checkbox toggled real overflow; unsupported scroll-state hint remained hidden; named scroller stayed available. — Source

Dependencies: Overflowing horizontal scroller with a scroll-state query container, Native demo-only checkbox changing content from overflow to wrapped without changing authored query CSS, Equal-specificity queried hint selector

Fallback: Firefox and WebKit retain horizontal scrolling and readable labels; the unsupported hint stays hidden. The preview-only checkbox still changes content layout.

Accessibility review: Only the named focusable demo region, native checkbox state, overflow geometry and visual opacity were automatically tested; labels are not functional tabs. The original 180ms transition remains under reduced-motion preference. Manual keyboard, zoom and screen-reader audit is pending.
