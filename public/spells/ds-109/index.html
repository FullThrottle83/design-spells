ds-109 / Media / 0 JS

Named View-Transition Cards (`view-transition-class` + typed `attr()`)

A shared-element transition between a list card and a detail page. `view-transition-name` is read from `id` as a `<custom-ident>`; `view-transition-class` groups the animation.

Zero JavaScript in this example. The catalogue has optional enhancements.

CSS

@supports (view-transition-name: none) {
  @view-transition { navigation: auto; }
}
@supports (x: attr(x type(*))) {
  .vt-card {
    view-transition-name: attr(id type(<custom-ident>), none);
    view-transition-class: card;
  }
}
::view-transition-group(*.card) {
  animation-duration: 320ms;
  animation-timing-function: cubic-bezier(.16,1,.3,1);
}
@media (prefers-reduced-motion: reduce) {
  ::view-transition-group(*),
  ::view-transition-old(*),
  ::view-transition-new(*) { animation: none !important; }
}
