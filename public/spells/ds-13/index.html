Spotlight Focus

The hovered card in a grid sharpens while its siblings recede.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="card-grid"><article class="destination-card" style="padding:1rem;border-radius:var(--radius-lg);background:var(--color-surface);box-shadow:0 1px 2px oklch(0.2 0.01 80 / .08)">Alpha</article><article class="destination-card" style="padding:1rem;border-radius:var(--radius-lg);background:var(--color-surface);box-shadow:0 1px 2px oklch(0.2 0.01 80 / .08)">Bravo</article><article class="destination-card" style="padding:1rem;border-radius:var(--radius-lg);background:var(--color-surface);box-shadow:0 1px 2px oklch(0.2 0.01 80 / .08)">Charlie</article></div>

CSS

.card-grid { display: grid; gap: var(--space-4); }
.card-grid:has(.destination-card:hover) .destination-card:not(:hover),
.card-grid:has(.destination-card:focus-within) .destination-card:not(:focus-within) {
  opacity: 0.65;
  transform: scale(0.985);
}
.destination-card {
  transition: opacity 300ms cubic-bezier(0.16,1,0.3,1), transform 300ms cubic-bezier(0.16,1,0.3,1);
}
