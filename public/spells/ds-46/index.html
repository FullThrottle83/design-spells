ds-46 / Scroll / 0 JS

Real Overflow Hint

Show edge fades, arrows, or “swipe me” hints only when the content is actually scrollable.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="tabs-wrap" style="max-width:20rem"><div style="display:flex;gap:1rem;white-space:nowrap;padding-inline-end:3rem;min-width:44rem"><span>Overview</span><span>Getting started</span><span>Pricing</span><span>Documentation</span><span>Changelog</span><span>Support</span><span>Community</span><span>Careers</span></div><div class="fade-hint">→</div></div>

CSS

.tabs-wrap {
  position: relative;
  overflow-x: auto;
  container-type: scroll-state;
}

.tabs-wrap .fade-hint {
  opacity: 0;
  transition: opacity 180ms ease;
}

@container scroll-state(scrollable: inline) {
  .fade-hint { opacity: 1; }
}
