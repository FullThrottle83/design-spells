ds-44 / Scroll / 0 JS

Sticky Shadow When Stuck

A sticky element gains extra shadow and border only once it is actually stuck. Much more premium than a permanent shadow.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<nav class="toc"><div class="toc__inner">On this page</div></nav>

CSS

.toc {
  position: sticky;
  top: 1rem;
  container-type: scroll-state;
}

.toc__inner {
  border: 1px solid transparent;
  transition: box-shadow 220ms ease, border-color 220ms ease, background 220ms ease;
}

@container scroll-state(stuck: top) {
  .toc__inner {
    background: oklch(from var(--color-bg) l c h / .86);
    border-color: var(--color-border);
    box-shadow: 0 12px 32px oklch(0 0 0 / .10);
  }
}

Browser-support guidance

Project category: Progressive. This hand-maintained registry is a dated estimate, not proof of browser behavior.

Support: registry-estimate; behavior: browser-tested; accessibility: not-audited.

Verification evidence

  • behavior (2026-09-26, chromium 151.0.7922.34): Scoped ds-44 test: at 900×700 the sticky nav reached its top inset, computed shadow appeared when stuck and returned to none after scrolling to top; scripts disabled, reduced motion. — Source
  • behavior (2026-09-26, firefox 153.0): Fallback observation: native sticky position reached the inset; scroll-state declaration unavailable and shadow stayed none. — Source
  • behavior (2026-09-26, webkit 26.5): Fallback observation: native sticky position reached the inset; scroll-state declaration unavailable and shadow stayed none. — Source

Dependencies: Native sticky positioning and a real document scroll runway, Scroll-state container query for the progressive shadow

Fallback: Native sticky navigation remains usable without scroll-state; the progressive shadow stays absent. The sample is not a complete table of contents.

Accessibility review: Only visual sticky/shadow state was automatically checked with scripts disabled and reduced-motion preference. Keyboard-only scrolling, 200% text/400% zoom, NVDA, VoiceOver, contrast and complete motion review remain untested.
