Seamless Edge Mask (`mask-image`)

The scroller’s own edges become literally transparent. Works regardless of the background color or pattern behind it.

Zero JavaScript in this example. The catalogue has optional enhancements.

CSS

.scroll-gallery {
  overflow-x: auto;
  overscroll-behavior-x: contain;
  mask-image: linear-gradient(
    to right,
    transparent 0%,
    black 5%,
    black 95%,
    transparent 100%
  );
  -webkit-mask-image: linear-gradient(to right, transparent 0%, black 5%, black 95%, transparent 100%);
}
