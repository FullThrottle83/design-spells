## Pilot 01 — why these six

Prefer established techniques before experimental ones. Fix the two confirmed unreachable/invisible results first (ds-21 and ds-95), then teach the same product standard across Interaction, Forms, State, Layout and Data. Ds-12 supplies a real horizontal scroll journey; ds-37 demonstrates environmental state without a mouse-only resize grip. Ds-5's existing baseline comparison is retained, not replaced. This does not duplicate ds-44–46.

### Source versus scenery

- **README.md + identical SKILL.md:** ds-5 adds keyboard underline and reduced motion; ds-16 disables label transitions with reduced motion; ds-21 adds a persistent target outline and removes its pulse with reduced motion; ds-95 fixes width, deliberately increases chart height from 5rem to 10rem, corrects the six-month data label, and adds keyboard emphasis and reduced motion.
- **scripts/showcase_fixtures.py:** explicitly demo-only copy, original embedded SVG print studies, scene composition and instructions. Shared fixture HTML flows into generated previewHtml and CSS-only integration examples (ds-37 uses a minimal native-resize integration fixture, not nonfunctional demo radio controls); authored ds-95 HTML remains canonical. No fake submission, purchase, deletion, or async state.

- **Integration bundles:** remain derived from canonical CSS and authored HTML (or labelled CSS-only fixture). They intentionally do not include scenic styles. Runnable downloads do. No preview-only selector amplifies the authored effect.
