ds-70 / Layout / Markup

Native Tree View Navigation (`<details>`)

A tree view for documentation or sidebars built from nested `<details>` elements, with no JS.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Raw snippets omit the shared base tokens. Download runnable HTML above for the demo fixture, required base tokens, and CSS in a single document. External images, if any, still need network access.

HTML

<nav class="tree-nav">
  <details open>
    <summary>Documentation</summary>
    <div class="tree-group">
      <a href="/docs/start">Get started</a>
      <details>
        <summary>Components</summary>
        <div class="tree-group">
          <a href="/docs/buttons">Buttons</a>
          <a href="/docs/cards">Cards</a>
        </div>
      </details>
    </div>
  </details>
</nav>
