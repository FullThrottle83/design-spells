Image-Clipped Gradient Headline

A headline filled with an image or gradient via `background-clip: text`.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Raw snippets omit the shared base tokens. Download runnable HTML above for the demo fixture, required base tokens, and CSS in a single document. External images, if any, still need network access.

HTML

<h1 class="paint-headline">Build faster. Ship prettier.</h1>

CSS

.paint-headline {
  text-wrap: balance;
  background-image: linear-gradient(120deg, var(--color-primary), oklch(.7 .2 320));
  -webkit-background-clip: text; background-clip: text;
  -webkit-text-fill-color: transparent; color: transparent;
}
@supports not ((-webkit-background-clip: text) or (background-clip: text)) {
  .paint-headline { color: var(--color-primary); background: none; }
}
