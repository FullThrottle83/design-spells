Pill Segmented Control Glow

Segmented pill selector with smooth active tab highlight and focus indicator.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="segmented"><button type="button" aria-pressed="true">Day</button><button type="button">Week</button><button type="button">Month</button></div>

CSS

.segmented {
  display: inline-flex;
  padding: .25rem;
  border-radius: 999px;
  background: var(--color-surface-offset);
}
.segmented button {
  min-block-size: 44px; min-inline-size: 44px;
  padding-inline: 1rem; border: 0; background: transparent; cursor: pointer;
}
.segmented button[aria-pressed="true"] {
  background: var(--color-bg);
  box-shadow: 0 1px 3px oklch(0 0 0 / .08), inset 0 1px 0 oklch(1 0 0 / .3),
    0 0 0 3px color-mix(in oklch, var(--color-primary), transparent 78%);
}
