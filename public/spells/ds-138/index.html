Drop Cap & Editorial Typography (`initial-letter`)

An editorial drop cap for lead paragraphs.

Zero JavaScript in this example. The catalogue has optional enhancements.

Open standalone demo ↗Download runnable HTML ↓

Complete source

Select the source and use your browser's copy command. Raw snippets omit the shared base tokens. Download runnable HTML above for the demo fixture, required base tokens, and CSS in a single document. External images, if any, still need network access.

HTML

<p class="prose-dropcap">Once upon a time there was a new standard for the web…</p>

CSS

.prose-dropcap::first-letter {
  color: var(--color-primary); font-weight: 700;
}
@supports (initial-letter: 3 2) {
  .prose-dropcap::first-letter { initial-letter: 3 2; margin-inline-end: .5rem; }
}
@supports not (initial-letter: 3 2) {
  .prose-dropcap::first-letter { float: left; font-size: 3.2rem; line-height: .8; padding-inline-end: .4rem; }
}
