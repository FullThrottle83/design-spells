Auto-Hide Header

The header slides away on scroll down and returns on scroll up. **Requires the Root scroll-state preset.**

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<header class="site-header">Auto-hide header</header><p class="demo-note">Needs the root scroll-state preset.</p>

CSS

.site-header {
  position: sticky;
  top: 0;
  z-index: 100;
  transition: transform 280ms cubic-bezier(0.16,1,0.3,1);
}

@container scroll-state(scrolled: bottom) {
  .site-header { transform: translateY(-100%); }
}
@container scroll-state(scrolled: top) {
  .site-header { transform: translateY(0); }
}
