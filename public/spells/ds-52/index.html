Organic Section Divider (`shape()`)

Responsive dividers between sections that feel editorial.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="section-divider" style="inline-size:min(22rem, 100%)"></div>

CSS

.section-divider {
  block-size: 5rem;
  background: var(--color-surface);
  clip-path: shape(
    from 0% 45%,
    line to 18% 58%,
    line to 42% 32%,
    line to 68% 62%,
    line to 100% 40%,
    line to 100% 100%,
    line to 0% 100%,
    close
  );
}
