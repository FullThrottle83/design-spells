Reading-Flow Grid (`reading-flow`)

When grid items are repacked with `dense` or explicit `order`, Tab and screen readers should follow the *visual* row order, not the DOM order. `flex-visual` / `flex-flow` for flex; `grid-columns` if column order is the semantically correct one.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

CSS

.pack-grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(16rem, 1fr));
  grid-auto-flow: dense;
  gap: var(--space-4);
}
@supports (reading-flow: grid-rows) {
  .pack-grid { reading-flow: grid-rows; }
}
