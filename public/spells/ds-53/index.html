Text-Box-Trim

Trims the font’s invisible leading above capitals and below the baseline. `padding: 1rem` is now exactly 1rem from the letter edges. Use this relentlessly on every button, chip, and card heading. The fallback is invisible.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<button class="btn">Trimmed</button> <span class="chip">Chip</span>

CSS

.btn, .badge, .pill, .chip {
  text-box-trim: trim-both;
  text-box-edge: cap alphabetic;
  line-height: 1;
}
