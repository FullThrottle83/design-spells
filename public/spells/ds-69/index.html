ds-69 / Scroll / 0 JS

Scroll-Aware Table Boundaries (`container-type: scroll-state`)

Tables with `position: sticky` show edge shadows and dividers *only* when the content has actually been scrolled horizontally.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

Live demo

Open standalone demo ↗Download runnable HTML ↓

Tab into the table, then use left/right arrows, or scroll sideways. The first column stays pinned. Supporting browsers add a shadow away from the start.

CSS

.table-wrapper {
  overflow-x: auto;
  container-type: scroll-state;
}

.table-wrapper th:first-child,
.table-wrapper td:first-child {
  position: sticky;
  left: 0;
  background: var(--color-bg);
  transition: box-shadow 200ms ease;
}

@container scroll-state(scrollable: left) {
  .table-wrapper th:first-child,
  .table-wrapper td:first-child {
    box-shadow: 8px 0 12px -4px light-dark(oklch(0 0 0 / .3), oklch(1 0 0 / .25));
  }
}
@media (prefers-reduced-motion: reduce) {
  .table-wrapper th:first-child, .table-wrapper td:first-child { transition: none; }
}
