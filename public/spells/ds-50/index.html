Focus Help Rail

Contextual help appears beside a field on `:focus-within`.

Zero JavaScript in this example. The catalogue has optional enhancements.

Select the source and use your browser's copy command. Shared design tokens are supplied by the demo environment, not included in these snippets.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="form-row"><label>API key<input></label><p class="help-rail">Keep this secret.</p></div>

CSS

.form-row {
  position: relative;
  anchor-scope: --help-anchor;
}

.form-row label {
  anchor-name: --help-anchor;
}

.form-row .help-rail {
  position: absolute;
  position-anchor: --help-anchor;
  position-area: right span-all;
  margin-left: .75rem;
  inline-size: 22ch;
  opacity: 0;
  transform: translateX(-6px);
  transition: opacity 180ms ease, transform 180ms ease;
}

.form-row:focus-within .help-rail {
  opacity: 1;
  transform: translateX(0);
}
