Scroll-Driven Header Compression

Shrinks the sticky header and scales the logo down as the user scrolls, without layout shifts.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<header class="site-header"><strong class="header-logo">Brand</strong></header><p class="demo-note">Bound to the real page scroll — scroll the whole catalogue, not this box.</p>

CSS

.site-header {
  position: sticky; top: 0; z-index: 100;
  padding-block: 1.25rem;
  transition: padding 150ms ease;
}

.header-logo {
  transform-origin: left center;
  transition: transform 150ms ease;
}

@supports (animation-timeline: scroll()) {
  .site-header {
    animation: shrink-header linear both;
    animation-timeline: scroll(root block);
    animation-range: 0px 120px;
  }
  
  .header-logo {
    animation: scale-logo linear both;
    animation-timeline: scroll(root block);
    animation-range: 0px 120px;
  }

  @keyframes shrink-header { to { padding-block: 0.5rem; } }
  @keyframes scale-logo { to { transform: scale(0.85); } }
}
