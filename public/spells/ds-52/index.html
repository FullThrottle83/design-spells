Organic Section Divider (`shape()`)

Responsive dividers between sections that feel editorial.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Raw snippets omit the shared base tokens. Download runnable HTML above for the demo fixture, required base tokens, and CSS in a single document. External images, if any, still need network access.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="section-divider" style="inline-size:min(22rem, 100%)"></div>

CSS

.section-divider {
  block-size: 5rem;
  background: var(--color-surface);
  clip-path: shape(
    from 0% 45%,
    line to 18% 58%,
    line to 42% 32%,
    line to 68% 62%,
    line to 100% 40%,
    line to 100% 100%,
    line to 0% 100%,
    close
  );
}
