Customizable Select (`appearance: base-select`)

A native `<select>` becomes fully styleable, including the open menu. Retires headless libraries for standard dropdowns.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<select class="premium-dropdown"><option>Overview</option><option>Reports</option><option>Settings</option></select>

CSS

@supports (appearance: base-select) {
  select.premium-dropdown {
    appearance: base-select;
    background: var(--color-surface);
    border: 1px solid var(--color-border);
    border-radius: var(--radius-md);
    padding: var(--space-2) var(--space-4);
  }

  select.premium-dropdown::picker(select) {
    background: oklch(from var(--color-bg) l c h / 0.92);
    backdrop-filter: blur(12px);
    border-radius: var(--radius-md);
    box-shadow: 0 12px 32px oklch(0 0 0 / 0.15);
    padding: var(--space-2);
  }

  select.premium-dropdown option:hover {
    background: var(--color-surface-offset);
    border-radius: var(--radius-sm);
  }
}
