Gradient Reveal on headings

A scroll-driven text reveal with `animation-timeline: view()`.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<h2 class="section-heading">A heading that reveals</h2>

CSS

@supports (animation-timeline: view()) {
  .section-heading {
    clip-path: inset(0 100% 0 0);
    animation: reveal-text linear both;
    animation-timeline: view();
    animation-range: entry 0% entry 60%;
  }
  @keyframes reveal-text { to { clip-path: inset(0 0 0 0); } }
}
