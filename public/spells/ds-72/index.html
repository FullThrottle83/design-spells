Scroll-Driven Staggered List

List and card items fade in sequence as the user scrolls, synced to viewport position.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<ul class="stagger-list"><li>One</li><li>Two</li><li>Three</li></ul>

CSS

@supports (animation-timeline: view()) {
  .stagger-list > * {
    animation: list-entry linear both;
    animation-timeline: view();
    animation-range: entry 5% entry 30%;
  }

  @keyframes list-entry {
    from {
      opacity: 0;
      transform: translateY(24px) scale(0.96);
    }
    to {
      opacity: 1;
      transform: translateY(0) scale(1);
    }
}
}
