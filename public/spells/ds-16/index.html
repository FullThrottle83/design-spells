Floating Labels

Always use a real `<label>`. The placeholder trick never replaces the label semantically.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="form-group"><input placeholder=" "><label>Your name</label></div>

CSS

.form-group { position: relative; }
.form-group input {
  width: 100%;
  padding: 1.4rem 1rem 0.55rem;
}
.form-group label {
  position: absolute;
  left: 1rem; top: 50%;
  transform: translateY(-50%);
  transform-origin: left top;
  pointer-events: none;
  transition: transform 220ms cubic-bezier(0.16,1,0.3,1), color 220ms cubic-bezier(0.16,1,0.3,1);
}
.form-group input:focus + label,
.form-group input:not(:placeholder-shown) + label {
  transform: translateY(-130%) scale(0.76);
  color: var(--color-primary);
}
