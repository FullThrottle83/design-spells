ds-33 / Layout / Markup

True Auto-Height (`interpolate-size`)

A modernization of Spell 15. Animates `block-size: 0` → `auto` directly. Bonus: `<details name="faq">` gives you an exclusive accordion automatically (siblings close when a new one opens).

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Shared design tokens are supplied by the demo environment, not included in these snippets.

HTML

<details>
  <summary>What is included?</summary>
  <div class="accordion-panel">A panel that expands to its intrinsic height.</div>
</details>

CSS

:root {
  interpolate-size: allow-keywords;
}

.accordion-panel {
  block-size: 0;
  overflow: hidden;
  transition: block-size 300ms cubic-bezier(0.16,1,0.3,1);
}

details[open] .accordion-panel {
  block-size: auto;
}
