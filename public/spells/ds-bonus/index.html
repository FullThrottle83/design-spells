Typographic Harmony (`text-wrap`)

Prevents orphaned single words at heading line ends using text-wrap balance and pretty.

Zero JavaScript in this example. The catalogue has optional enhancements.

Select the source and use your browser's copy command. Shared design tokens are supplied by the demo environment, not included in these snippets.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<h2 class='text-balance'>Typographic harmony on a long heading</h2><p class='text-pretty'>Pretty wrapping keeps orphans off the last line of a paragraph.</p>

CSS

h1, h2, h3, h4, .text-balance { text-wrap: balance; }
p, li, .text-pretty { text-wrap: pretty; }
