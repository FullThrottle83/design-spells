External Link Nudge

An outbound link indicator icon that nudges outward on hover.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Raw snippets omit the shared base tokens. Download runnable HTML above for the demo fixture, required base tokens, and CSS in a single document. External images, if any, still need network access.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<a href="https://example.com" target="_blank" rel="noopener">Docs <span class="external-icon">↗</span></a>

CSS

a[target="_blank"] .external-icon {
  display: inline-block;
  opacity: .55;
  transition: transform 180ms cubic-bezier(0.16,1,0.3,1), opacity 180ms cubic-bezier(0.16,1,0.3,1);
}
a[target="_blank"]:hover .external-icon,
a[target="_blank"]:focus-visible .external-icon {
  transform: translate(.3rem, -.3rem);
  opacity: 1;
}
