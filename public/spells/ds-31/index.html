ds-31 / Reveal & motion / Markup

Phantom Entry (`@starting-style`)

A soft fade-in from `display: none` with no JS. Perfect for popover menus (`[popover]`) and native modals.

Zero JavaScript in this example. The catalogue has optional enhancements.

Complete source

Select the source and use your browser's copy command. Shared design tokens are supplied by the demo environment, not included in these snippets.

HTML

<button type="button" popovertarget="ph-pop">Open menu</button>
<div id="ph-pop" popover="auto" class="popover-menu">
  <a href="/docs">Documentation</a>
</div>

CSS

.popover-menu {
  display: none;
  opacity: 0;
  transform: translateY(-8px) scale(0.96);
  transition: opacity 240ms cubic-bezier(0.16,1,0.3,1),
              transform 240ms cubic-bezier(0.16,1,0.3,1),
              display 240ms allow-discrete;
}
.popover-menu:popover-open,
.popover-menu.is-open {
  display: block;
  opacity: 1;
  transform: translateY(0) scale(1);
}
@starting-style {
  .popover-menu:popover-open,
  .popover-menu.is-open {
    opacity: 0;
    transform: translateY(-8px) scale(0.96);
  }
}
