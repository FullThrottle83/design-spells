ds-55 / Scroll / 0 JS

Sticky Card Deck

Cards stack like a deck as the user scrolls. Scale and dimming stay synced to the exit-crossing.

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

Live demo

Open standalone demo ↗Download runnable HTML ↓

Scroll slowly: each chapter pins near the top as the next covers it. Scroll back to revisit. Scale and dimming are progressive enhancements.

CSS

.card-stack { display: flex; flex-direction: column; gap: var(--space-4); }

.card-stack .card {
  position: sticky;
  top: max(2rem, var(--header-height, 0px));
  transform-origin: top center;
}

@supports (animation-timeline: view()) {
  .card-stack .card {
    animation: stack-shrink linear both;
    animation-timeline: view(block);
    animation-range: exit-crossing 0% exit-crossing 100%;
  }
  @keyframes stack-shrink {
    to {
      transform: scale(0.92) translateY(-0.5rem);
      filter: brightness(0.6);
    }
}
}
@media (prefers-reduced-motion: reduce) {
  .card-stack .card { animation: none; }
}
