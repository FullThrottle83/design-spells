ds-69 / Scroll / 0 JS

Scroll-Aware Table Boundaries (`container-type: scroll-state`)

Tables with `position: sticky` show edge shadows and dividers *only* when the content has actually been scrolled horizontally.

Zero JavaScript in this example. The catalogue has optional enhancements.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<div class="table-wrapper" style="max-width:20rem"><table style="min-width:44rem"><tr><th>Name</th><th>Plan</th><th>Seats</th><th>Region</th><th>Owner</th><th>Renewal date</th><th>Status</th></tr><tr><td>Acme Corporation</td><td>Pro</td><td>24</td><td>EU-West</td><td>Jonas Andersson</td><td>2026-11-04</td><td>Active</td></tr></table><p class="demo-note">Scroll the table sideways.</p></div>

CSS

.table-wrapper {
  overflow-x: auto;
  container-type: scroll-state;
}

.table-wrapper th:first-child,
.table-wrapper td:first-child {
  position: sticky;
  left: 0;
  background: var(--color-bg);
  transition: box-shadow 200ms ease;
}

@container scroll-state(scrolled: inline) {
  .table-wrapper th:first-child,
  .table-wrapper td:first-child {
    box-shadow: 4px 0 12px oklch(0 0 0 / 0.1);
  }
}
