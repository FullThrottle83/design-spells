Customizable Select Checkmark (`::checkmark` + `::picker-icon`)

Full native select chrome: a custom chevron (`::picker-icon`) and a checkmark on the selected option (`::checkmark`). Requires `appearance: base-select` (Spell 54).

The spell and its demo use zero JavaScript. Optional copy controls do not affect the example.

HTML

This is demonstration fixture markup; the technique does not require a specific HTML structure.

<select class="premium-dropdown"><option>One</option><option selected>Two</option><option>Three</option></select>

CSS

@supports (appearance: base-select) {
  select.premium-dropdown {
    appearance: base-select;
    min-block-size: 44px;
  }
  select.premium-dropdown::picker-icon {
    content: "▾";
    color: var(--color-text-muted);
    transition: transform 180ms cubic-bezier(.16,1,.3,1);
  }
  select.premium-dropdown:open::picker-icon { transform: rotate(180deg); }
  select.premium-dropdown option {
    min-block-size: 44px;
    display: flex; align-items: center; gap: .5rem;
    padding-inline: .75rem;
  }
  select.premium-dropdown option::checkmark {
    content: "✓";
    color: var(--color-primary);
    font-weight: 700;
  }
}
